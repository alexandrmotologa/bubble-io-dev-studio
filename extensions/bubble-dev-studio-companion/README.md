# Bubble Dev Studio Companion (Chrome / Edge Extension)

Lightning-fast 1-click AST & blueprint synchronization between Bubble.io Editor and Bubble Dev Studio Desktop.

## How to Install in Google Chrome or Microsoft Edge (Takes 15 Seconds)

1. Open **Google Chrome** (or Edge) and go to:
   ```
   chrome://extensions
   ```
2. Enable **Developer mode** toggle in the top right corner.
3. Click the **"Load unpacked"** button in the top left.
4. Select this directory:
   ```
   b:\workgit\bubble-io-dev-studio\extensions\bubble-dev-studio-companion
   ```

## How to Use

1. Open your Bubble application editor tab in Chrome (e.g. `https://bubble.io/page?id=your-app-id`).
2. A floating **"⚡ Sync to Dev Studio"** button will appear in the bottom right corner of the Bubble Editor.
3. Click it! In under 1 second, your full application AST (all pages, UI elements, workflows, and database types) will be streamed directly into Bubble Dev Studio over port `41890`.
